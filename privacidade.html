Política de privacidade

Responsável: Vinicius Campos Bergamo
Contato: berg.aaapb@gmail.com
Vigência: 5 de outubro de 2026.

A integração utiliza YouTube API Services exclusivamente para as funções do próprio canal @tanuki-kamesensei. Não oferece contas nem gerenciamento de canais de terceiros. Os dados da API são usados somente para o envio e a consulta de vídeos do canal e para diagnóstico técnico.

Os escopos solicitados são youtube.upload e youtube.readonly. As funções tratam vídeos, capas, títulos, descrições, identificadores do canal e dos vídeos, respostas de status e credenciais OAuth. A autorização ocorre pelo Google, sem fornecer sua senha à integração. O workflow usa n8n e uma VPS. Vídeos, capas e metadados são enviados ao YouTube nos uploads. O tratamento pelo Google é descrito em https://policies.google.com/privacy.

Os dados obtidos pela API não são vendidos, compartilhados com terceiros nem usados para publicidade. Registros de execução podem conter dados usados pelas funções do canal. Não se declara aqui um prazo automático de retenção ou uma rotina de limpeza já configurada. Tokens devem ser mantidos somente enquanto necessários e autorizados. Você pode revogar acesso em https://security.google.com/settings/security/permissions.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Pedidos de exclusão devem ser enviados a berg.aaapb@gmail.com. O responsável se compromete a atender manualmente o pedido e excluir dados locais associados assim que possível, em até 7 dias corridos. A exclusão local não apaga vídeos no YouTube; use o YouTube Studio para removê-los.

O site informativo não inclui cookies ou analytics próprios. GitHub Pages registra o IP dos visitantes para segurança, mesmo sem login. Consulte https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement. Alterações nas práticas serão refletidas na política.
